# 右栏的讲解动画

动画写在 `Story.film` 里，放在文章右栏（宽屏吸附在右边，窄屏在对话上方），带小念和爸爸的语音讲解。引擎在 `src/learning/film/`（`engine.ts` 时间线、`stage.ts` 画面、`player.ts` 播放器、`narration.ts` 按配音长度拉长时间线）。画布固定 1200×900，坐标都是 `[x, y]`，y 往下增大。每个元素只由时间 t 决定，所以能暂停、拖动、从任意一帧看。

**配音会把戏拉长，对话跟着高亮**：有声音时，一场戏（或配同一轮的几场戏）要等这一轮小念和爸爸的两句读完，整场按比例放慢，`from`/`to`、`travel`、`over`、`rise`、`tint`、`slide`、`amount`、镜头 `t` 一起拉长；`flow`、`pulse`、`wave`、抖动、摆动、打字、画箭头保持原速。所以戏照原速写，元素先后顺序对上爸爸说话的顺序就行。没配到戏的轮次（通常是最后的总结）接在前一场后面读。播放时左边对话会高亮并滚到正在读的那一轮、那个人。

**每一场演爸爸这一轮讲的东西**：天文最适合演——地球歪着绕太阳转、月亮钻进地球影子、光线擦过黑洞拐弯、空间像气球一样胀大、火箭喷气往前冲。点对话里的「🎬 看动画」，就从这一轮的第一场开始播。

## 规矩（检查器会拦，`stories/rules.ts`）

- 一轮问答配一到三场戏：至少 4 场；第一场配第 1 轮（`turn: 0`）；`turn` 按对话顺序只能不变或变大；最多跳过 1 轮（总结轮通常不配戏）；同一轮不超过 3 场。
- 每场 4–14 秒，全片 30–150 秒（这是不配音时的长度；配音后通常会拉长到 2–4 分钟）。
- 每场至少 2 个元素，任何时刻同屏不超过 8 个，用 `to` 把旧元素收走。
- `from` ≤ 时长 − 0.8；`to` ≥ `from` + 0.5，且不超过时长。
- 镜头 `zoom` 1–2.6。
- 文字长度：场次标题 ≤12、`label` ≤12、`text` ≤14、`arrow` ≤10、`shape` ≤7、`meter` / `count` 标签 ≤8、`myth` 每句 ≤18。
- `ray` 至少 2 个点；`swing` 摆角 0–80°；`toss` 的地面要在出手点下方。
- 左上角留给场次标题，别把元素放在 y < 140 的左上角。

## 画法

1. **逐步长出来**：按爸爸台词的先后一个个加元素，间隔 0.6–1.5 秒。说到哪个，哪个才出现。
2. **比方要画出来**：爸爸说「像手电筒照篮球」，就画一个 `shape` 球加一束 `ray`；说「像气球上的点」，就让几个 `atom` 一起 `slide` 散开。
3. **误区要翻过来**：爸爸说破误区的那一轮放 `myth` 卡，先划掉错的，再亮出对的。
4. **字要少**：屏幕上只放关键词，完整的话交给旁边的对话。
5. **结尾一句**：每场最后用一行 `text` 点题（≤14 字），放在下方 y≈760–830。
6. **后写的盖在上面**：`cues` 的顺序就是画的顺序；深色背景（太空用 `shape` rect 深紫 `#1c1836`）写在最前，标签、`text` 写在最后。
7. **深色背景上的字要亮**：太空底上 `text` / `label` 用浅色（`#fff8dc`、`#ffd43b`、`#c5b3e6`）；浅底上用默认墨色或星空紫 `#5b3e96`。写完在联系表里看清楚每个字。
8. **误区卡占底部**：有 `myth` 的那场，y > 720 的地方别再放东西（点题的 `text` 往上挪到 y≈700，或不要）。
9. **会动的东西真的动**：行星、卫星、飞船用 `sprite` / `atom` 沿 `path` 走（圆轨道就给一串圆周上的点）；`shape` 用 `slide` 平移；别用「先收走、再在新位置放一个」冒充移动。有多个点的 `sprite` 在 `from` 之前是看不见的：要它先停着、过一会儿再走，就放一个只有起点、`to: X` 的静止副本，走的那个写 `from: X`。
10. **天文要对**：公转方向（从北极上空看是逆时针）、月相亮面朝向太阳、影子在背光一侧、地轴倾斜方向全年不变、光线直线传播（只在介质边界或强引力处拐弯）；不按比例时在画面角落写「示意」。
11. **数字只用爸爸说过的**：`count`、`meter` 的标签和 `text` 里出现的数，爸爸这一轮里都要说过；只想表现「多 / 少」就用 `meter`。

## 元素一览（`types.ts` 的 `Cue`）

| kind | 用来 | 主要字段 |
|---|---|---|
| `text` | 一行大字点题 | `at`、`text`、`size: 's'/'m'/'l'`、`color` |
| `formula` | 公式逐字打出 | `at`、`text` |
| `label` | 带引线的标签 | `at`（指向点）、`pos`（文字位置）、`text` |
| `atom` | 带字的小球：行星、卫星、光子、粒子；多点 `path` 时沿路线走 | `path`、`symbol`、`color`、`r`、`travel`、`motion` |
| `bond` | 两点之间的一根线（引力连线、天线、绳） | `a`、`b` |
| `shape` | 太阳、地球、本影锥、背景、望远镜……可写字、变色、`slide` 平移、`grow`/`shrink` | `shape`、`at`、`size`、`color`、`text`、`tint`、`motion`、`slide`、`outline` |
| `vessel` | 容器液面涨落（少用：燃料箱、水杯实验） | `vessel`、`at`、`size`、`liquid`、`level`、`rise`、`tint`、`label` |
| `particles` | 星云气体聚拢、太阳风粒子、尘埃、星星群 | `box`、`count`、`color`、`motion: 'gas'/'jitter'/'rise'`、`amount` |
| `sprite` | 一个 emoji 弹出或沿路线走（🌍 🌙 🚀 🛰️ 🔭 ☄️ 🧒） | `icon`、`path`、`size`、`travel`、`wobble` |
| `arrow` | 一笔画出的箭头（引力、速度、光线方向） | `path`、`text`、`color` |
| `flow` | 一串小点沿路线流（太阳风、信号、喷气、星光） | `path`、`count`、`speed`、`loop` |
| `pulse` | 一圈圈波纹（脉冲星、爆发、信号发射） | `at`、`radius`、`rate` |
| `wave` | 从 a 往 b 传过去的一列波（电磁波、引力波、无线电） | `a`、`b`、`amplitude`、`wavelength`、`speed` |
| `ray` | 一束光沿路线画过去，拐点就是折射、引力透镜 | `path`、`color`、`draw` |
| `swing` | 挂着来回摆的小球（少用：傅科摆） | `pivot`、`length`、`angle`、`period`、`damping`、`icon` |
| `toss` | 抛出去的东西：真抛物线，落地停下（月球上跳、牛顿大炮的近距离段） | `at`、`velocity`、`gravity`、`ground`、`icon` |
| `meter` | 进度条涨落（温度、速度、亮度） | `at`、`label`、`start`、`end`、`over` |
| `count` | 数字从 start 数到 end（年份、距离、光年） | `at`、`label`、`start`、`end`、`unit` |
| `myth` | 误区卡：划掉错的、换成对的 | `wrong`、`right` |

所有元素都有 `from`（出现秒数）和可选的 `to`（消失秒数）。镜头 `camera: [{ t, at, zoom }]` 可以推近看细节。

## 常用配方

- **公转 / 自转**：`shape` 太阳在中心，`sprite` 🌍 沿圆周 `path` 走（12–24 个点就够圆）；地轴用一根倾斜的 `bond` 跟着平移。
- **月相 / 日月食**：`ray` 从左边平行射来；`shape` 地球、月亮；本影用深色 `shape` pill 或 rect，`tint` 让月亮变红。
- **轨道速度**：几个 `toss` 或 `sprite` 以不同速度出发，比谁绕回来；`meter` 速度。
- **引力弯曲光线**：`ray` 的 `path` 在黑洞旁拐弯；`shape` 黑洞 + `pulse` 吸积盘发光。
- **宇宙膨胀**：几个 `atom` 星系同时 `slide` 远离中心；`count` 数亿年。
- **恒星演化**：`particles` 气体 `amount` 由多到少聚拢 → `shape` 恒星 `grow` → `tint` 变红 → `pulse` 爆发。
- **信号传回地球**：`flow` 沿 `path` 从探测器经中继星到地面站；`count` 数延时秒数。
- **火箭反冲**：`flow` 向后喷气，`sprite` 🚀 沿 `path` 往前走，两个 `arrow` 标出作用力和反作用力。

写完先跑 `npm run story:frames -- <slug>`，看 `.story-preview/<slug>-frames.png`：每场一行三帧，元素不重叠、字不出框、深色底上字看得清、该出现的都出现了。再配音（`npm run voice -- <slug>`），在浏览器里开着声音从头听一遍。

## 一轮配几场戏

- 大多数轮一场就够。爸爸一句话里讲了两件事（「先……再……」），就拆成两场，`turn` 写同一个数，按顺序排。
- 同一轮最多 3 场；点「🎬 看动画」从这一轮的第一场开始，播完自动接下一场。
- 动画只给「看」，自己动手的交给互动图和「🔭 3D 实验台」；一场讲清一件事，台词留在文章里。
