# 写问答

文章写在 `src/learning/stories/<slug>.ts`，导出一个 `Story`（类型见同目录 `types.ts`），登记在 `stories/index.ts`（CRLF 换行）。`npm run story:new -- <slug>` 会把这两步做好。写完跑 `npm run story:check -- <slug>`，再跑 `npm run voice -- <slug>` 配音。

## 对话会被读出来

小念和爸爸的每一句都是配音稿（小念 `zh-CN-YunxiaNeural`，爸爸 `zh-CN-YunxiNeural` 慢 5%），播放动画时左边对话跟着声音逐句高亮。所以：

- 写成嘴上说得出的话。公式和符号放进 `eq`（只显示、不读），句子里说中文：「每秒约 7.9 千米」「大约 1.5 亿千米」「400 万倍太阳质量」。
- 非写符号不可时，`src/learning/voice.ts` 的 `speakable()` 会把这些换成读法：`km/s` `m/s` `km` `AU` `μs` `M☉` `R☉` `℃` `K` `°` `%` `10%～15%` `1/81` `米/秒` `−5` `3–5` `E = mc²` `F = ṁ·v` `Rs` `M87*` `Ia 型` `109P/` `GPS` `JWST` `L2` `CO₂` `H₂O`。
- `NASA`、`ESA`、`LIGO`、`FAST`、`DESI`、`EHT`、`M87`、`3D` 这类缩写和人名里的间隔号（「乔瑟琳·贝尔」）edge-tts 能念，`story:check` 也不提醒；其余念不顺的英文串、上下标、`/ = × ≈ →` 等符号会给 ⚠️，要么换成中文说法，要么在 `speakable()` 里补一条读法（`tests/voice.test.ts` 里加一行例子）。
- 改了任何一句对话的字，都要重跑 `npm run voice -- <slug>`；`tests/voice.test.ts` 会查每句配音读的是不是现在的文字。

## 字段

| 字段 | 写什么 |
|---|---|
| `slug` | 和 `curriculum.ts` 里的课一致 |
| `title` | 小念口吻的问题，必须带「？」，和 curriculum 的 `question` 一致：「到了月球上我会变轻吗，体重秤上的数字为什么会变？」 |
| `trigger` | 小念刚遇到的那件事，一句话、具体到场景：「看阿波罗登月纪录片时，小念发现航天员……在月球上却像袋鼠一样一蹦老远。」 |
| `dialogue` | 5–8 轮 `{ nian, dad, eq?, figure?, show? }` |
| `tip` | 给大人：观测安全、数字的口径（「截至 2025 年」）、和课本写法的差别、今晚能一起看的天象或在家能做的小实验；至少 20 字 |
| `sources` | 参考来源，至少 2 条，见 sources.md |
| `film` | 讲解动画，每篇都要有，见 film.md |

每轮里：
- `eq`：这一轮的公式或数据条，单独排一行（`重力 G = m·g，月球 g ≈ 1.62 m/s²`、`1 光年 ≈ 9.46 万亿千米`）。入门的题尽量不放公式，进阶最多一两条，综合可以多一些。
- `figure`：爸爸边说边指的一张图，见 figures.md。
- `show`：`{ kind: 'lab', step, label }` 记下这一轮对应 3D 实验台第 `step` 段（从 0 数，`label` 要包含那一段的标题）；或 `{ kind: 'steps', frames }` 一排 2–4 格的小图解（emoji + ≤8 字）。

## 检查器会拦的（`stories/rules.ts`）

- 5–8 轮；标题带「？」；`trigger` 一句话（≥8 字）。
- 除最后一轮外，小念每句都带「？」。
- 从第 2 轮起，小念的问题要用上爸爸上一句里的一个有意义的两字词（「质量」「引力」「本影」；「什么」「这个」不算）。检查器取相邻两个汉字，其中一个是「的了吗呢吧呀啊哦嘛是我你他她它们这那就也都还又在有和么什怎为个一不没会要说想看能可以得很太好真再」这类虚字就不算；最稳的是让小念原样复述爸爸刚说的一个名词：「质量不变、重量变了？」。
- 最后一轮小念以「我懂了」或「我明白了」开头。
- 爸爸每句 20–180 字；`tip` 至少 20 字；`sources` 至少 2 条 https，不能是 OpenStax。

## 写好的标准（检查器管不到的）

**小念**：孩子的口气，短句，带情绪：「哇，月亮怎么变成红色的了！」。追问顺着爸爸刚说的新词往下挖，不跳题：爸爸说了「本影」，小念就问「本影是全黑的吗？」。小念可以先说出那个常见的错误想法（「是不是一到月球身体就变轻、变少了？」），让爸爸接着说破——这是破误区最自然的写法。

**爸爸**：
- 第一句就给答案，再解释。
- 一个比方只讲一件事，用孩子见过的东西：手电筒照篮球（月相、四季）、旋转木马（公转、离心）、拉面团 / 气球上画点（宇宙膨胀）、蹦床上放保龄球（时空弯曲）、水管里的水流（太阳风）、救护车鸣笛由高变低（红移）。比方有漏洞就说一句「别全信这个比方」。
- 比方说完说真名，只说一次：「……这就叫潮汐锁定。」后面就直接用。
- **尺度要能感受到**：天文数字太大，换成孩子能想的：「坐时速 350 千米的高铁不停开，也要将近 50 年才到太阳」「如果太阳是篮球，地球就是 26 米外的一粒芝麻」。换算要算对，写进 `tip` 或心里核一遍。
- 数字要真实、可查（写进 `sources`）；图里和动画里出现的数字只能是爸爸说过的。不确定就直说「科学家还在研究」或「大约」。
- 误区点名说破：「很多人以为……，其实……」，再给一个孩子能自己验证的证据（今晚看月亮的位置、用手电筒和球做个实验、看一段天宫课堂）。
- 不堆术语：「参考系」「光度」「红移」这类词，入门题不说；进阶、综合题要用就先打比方。
- 学段对齐：入门题讲现象和定性道理；进阶题可以讲简单比例和数字；综合题可以讲公式，但先讲道理再给公式。
- **说清楚哪些还不知道**：暗物质、暗能量、大爆炸之前、外星生命，要明确告诉孩子「这是科学家正在找答案的问题」。

**追问链的常见顺序**（不必每次全用）：
1. 看到的现象是怎么回事（是什么）
2. 天上实际在发生什么（谁绕着谁转、光走了什么路、引力在拉谁）
3. 为什么非得这样，不这样会怎样
4. 常见误区或特例
5. 我今晚能去看什么、怎么看 / 科学家是怎么知道的
6. 小念总结，爸爸肯定并给一个能去看的天象或能回家做的小实验

## 例子（`moon-gravity.ts` 的前两轮）

```ts
{
  nian: '爸爸，航天员在月球上蹦得像袋鼠一样轻飘飘，是不是一到月球，身体就变轻、变少了？',
  dad: '你身上一块肉都没少！科学家把“身体里含有多少物质”叫作质量，你现在是 30 千克，带到月球、火星还是 30 千克。真正变了的是重量——也就是星球把你往下拉的力气，月球拉人的力气只有地球的大约六分之一。',
},
{
  nian: '质量不变、重量变了？那我站上月球的体重秤，数字会变成多少？',
  dad: '体重秤量的其实是你往下压它的力气。……',
  eq: '重力 G = m·g，月球 g ≈ 1.62 m/s² ≈ 地球的 1/6',
  figure: { kind: 'sim', sim: 'moonJump', caption: '换换星球、改改体重：……' },
},
```

第 1 轮小念说出了误区，爸爸当场说破；第 2 轮的「质量」「重量」接的是爸爸上一句的原话，这就是追问链。

## 草稿怎么改

`story:new` 生成 6 轮骨架：第 1 轮预填了 curriculum 的 `question` 和 `takeaway`，其余是括号里的提示；有 3D 实验台的课会预填 `show.lab` 段号。改写时：
- 把括号提示全部换成真对话，并掉或删掉多余的轮次，控制在 5–8 轮；
- 3D 实验课保留需要的 `show.lab`（段号和 `labs/index.ts` 的 `steps` 对得上），删掉用不上的；
- 把注释掉的 `// figure:` 换成真的图，把 `sources`、`tip`、`film` 填上。
